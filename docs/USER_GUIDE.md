# 📘 TechIntern — Руководство пользователя (фронтенд)

Полное описание интерфейса: каждый экран, каждая функция и каждая кнопка — что делает и куда ведёт.
Документ построен как **сквозной сценарий (end-to-end)**: сначала общие элементы, затем путь
**студента**, затем путь **компании**, и в конце — общие разделы.

---

## 0. Общие элементы интерфейса

Эти элементы доступны почти на каждом экране после входа.

### Боковое меню (сайдбар)
На десктопе закреплено слева, на телефоне открывается кнопкой‑гамбургером (☰) в шапке.
Содержимое меню зависит от роли:

| Студент | Компания |
|---------|----------|
| 🏠 Главная | 🏠 Дашборд |
| 🔍 Поиск вакансий | 💼 Мои вакансии |
| 📨 Мои отклики | 👥 Кандидаты |
| 👤 Профиль | 💬 Сообщения |
| 📚 Career Hub | 🏢 Профиль компании |
| 💬 Сообщения | ⚙️ Настройки |
| ⚙️ Настройки | |

Активный пункт подсвечивается. Клик переводит на соответствующий раздел.

### Верхняя панель (шапка)
- **☰ (гамбургер)** — только на телефоне: открывает/закрывает боковое меню.
- **☀️ / 🌙 (переключатель темы)** — выпадающее меню с тремя вариантами:
  - **Светлая** — всегда светлая тема.
  - **Тёмная** — всегда тёмная тема.
  - **Системная** — подстраивается под настройку вашей ОС.
  Выбор сохраняется и применяется без «вспышки» при следующих заходах.
- **Аватар (меню пользователя)** — клик открывает выпадающее меню:
  - Имя и email (информационно).
  - **Мой профиль / Профиль компании** — переход в профиль.
  - **Настройки** — переход в настройки.
  - **Выйти** — завершает сессию и возвращает на главную.

## 1. Первое знакомство (публичные страницы)

### 1.1. Главная (лендинг) — адрес `/`
Маркетинговая страница для незарегистрированных гостей.

**Шапка лендинга:**
- **Логотип TechIntern** — клик ведёт на главную.
- **Переключатель темы** — см. выше.
- **«Войти»** — переход на страницу входа.
- **«Начать бесплатно»** — переход на регистрацию.
- Если вы уже вошли, вместо двух кнопок появляется **«Открыть приложение»** — переход в личный кабинет.

**Блоки страницы (сверху вниз):**
1. **Hero (главный экран)** — заголовок, описание и две кнопки:
   - **«Начать бесплатно»** → регистрация.
   - **«У меня есть аккаунт»** → вход.
   - Справа — живой «превью‑виджет»: кольцо совпадения 92%, полосы навыков и подсказка «Добавьте Redux +15%».
2. **Статистика** — 4 ключевые цифры рынка (120 000 студентов, 80% вакансий с опытом и т. д.).
3. **Возможности** — 6 карточек с описанием функций.
4. **«Путь от профиля до оффера»** — 5 шагов пользовательского сценария.
5. **Призыв к действию** — кнопка **«Создать аккаунт»** → регистрация.
6. **Подвал** — логотип и копирайт.

### 1.2. Регистрация — адрес `/register`
- **Переключатель роли** — две большие карточки:
  - **«Я студент»** (ищу стажировку),
  - **«Я компания»** (ищу таланты).
  Выбор меняет подписи в форме (например, «Имя и фамилия» ↔ «Название компании»).
- **Кнопки OAuth** (если настроены ключи) — **Google** и **GitHub**: вход в один клик без пароля.
- **Поля:** имя/название, email, пароль (минимум 8 символов).
- **«Создать аккаунт»** — регистрирует и сразу авторизует, перебрасывая в личный кабинет.
- **«Войти»** (внизу) — если аккаунт уже есть.

### 1.3. Вход — адрес `/login`
- **Кнопки OAuth** — Google / GitHub (если настроены).
- **Поля:** email и пароль.
- **«Войти»** — авторизует и переводит в кабинет.
- **Блок «Демо‑доступы»** — кнопки‑ярлыки:
  - **«Студент»** — подставляет `student@techintern.ru`.
  - **«Компания»** — подставляет `company@techintern.ru`.
  - Пароль для обоих: `password123`.
- **«Зарегистрироваться»** — переход на регистрацию.

> После входа через Google/GitHub вы кратко увидите экран‑загрузчик (`/auth/callback`) — это
> система завершает авторизацию и переводит вас в кабинет.

## 2. Сценарий СТУДЕНТА (end-to-end)

Войдите как `student@techintern.ru` / `password123` (это профиль Алексея Смирнова).

### 2.1. Главная студента — `/app`
- **Приветствие** — «Привет, Алексей 👋».
- **4 карточки‑метрики:**
  - **Средний прогресс навыков** — средний % по вашему Skill Tree.
  - **Активных откликов** — сколько откликов в работе.
  - **Офферов** — сколько офферов получено.
  - **Пройдено материалов** — прогресс по Career Hub (X из Y).
- **«Рекомендуем вам»** — 3 подходящие вакансии. Кнопка **«Все вакансии»** ведёт в поиск.
- **«Последние отклики»** — 2 последних отклика с мини‑трекером. Кнопка **«Все отклики»** ведёт в раздел откликов.
- Любая **карточка вакансии** кликабельна → открывает детальную страницу.

### 2.2. Поиск вакансий — `/app/vacancies`
Главный инструмент студента — глубокий поиск по технологиям.

**Верхняя строка:**
- **Поле поиска** — ищет по должности, технологии, компании. Срабатывает автоматически (с задержкой ~0,3 с).
- **Сортировка** — выпадающий список: **«Сначала новые»** / **«По зарплате»**.
- **«Фильтры»** (только на телефоне) — открывает панель фильтров во всплывающем окне.

**Панель фильтров (слева на десктопе):**
- **«Технологии (точный стек)»** — ключевая функция. Кнопка **«Добавить технологию»** открывает список навыков по категориям; отмеченные становятся «чипами» над кнопкой. Клик по чипу (✕) убирает его. Вакансия попадёт в выдачу, только если содержит **все** выбранные технологии — это и есть «глубокий» фильтр (React + TypeScript, а не просто «Frontend»).
- **«Формат работы»** — Офис / Удалёнка / Гибрид / Любой.
- **«Тип занятости»** — Стажировка / Частичная / Полная / Любой.
- **«Уровень»** — Стажёр / Junior / Middle / Любой.
- **«Город»** — текстовый фильтр.
- **«Сбросить»** — очищает все фильтры и поиск.

**Результаты:**
- Счётчик найденных вакансий.
- **Карточки вакансий**: логотип компании, название, бейджи (уровень, формат, тип), технологии, зарплата, число откликов, дата, и (если вы вошли как студент) **процент совпадения** в углу.
- **Пагинация** — стрелки **‹** / **›** и индикатор «страница X из Y».
- Клик по карточке → детальная страница вакансии.

### 2.3. Детальная страница вакансии — `/app/vacancies/:id`
- **«К поиску»** — кнопка возврата к списку.
- **Шапка** — логотип, название, компания, бейджи, зарплата, город, требуемый опыт, полный список технологий (желательные помечены).
- **Описание, Обязанности, Требования, Условия** — подробные блоки.
- **Боковая панель «Ваш отклик»:**
  - **«Откликнуться»** — открывает окно отклика:
    - Поле **«Сопроводительное письмо»** (необязательно).
    - **«Отправить отклик»** — отправляет; появляется тост‑уведомление, отклик попадает в «Мои отклики».
    - **«Отмена»** — закрывает окно.
  - Если вы уже откликнулись — вместо кнопки показан текущий статус.
  - **AI‑оценка совпадения** — кольцо с процентом, разбивка (Навыки / Текст / Уровень), список совпавших навыков, список «Что добавит баллов» (например, «+15%») и текстовые объяснения.

### 2.4. Профиль и Skill Tree — `/app/profile`
Сердце профиля студента.

**Шапка профиля:**
- Аватар, имя, бейдж **«Открыт к предложениям»** (если включено), заголовок, уровень, специализация, город, вуз/курс, ссылки **GitHub** и **Портфолио**.
- **«Редактировать»** — открывает окно редактирования профиля:
  - Поля: имя, город, заголовок, «О себе», вуз, курс, специализация, уровень, опыт (лет), Telegram, GitHub, сайт.
  - Переключатель **«Открыт к предложениям»** — показывать ли профиль компаниям.
  - **«Сохранить»** / **«Отмена»**.

**Вкладки профиля:**

**Вкладка «Дерево навыков»:**
- **Чипы направлений** сверху — например, «Frontend 46%», «Backend 50%».
- **Skill Tree (дерево навыков)** — иерархия с прогресс‑полосами по каждому навыку:
  - **▸ (стрелка‑шеврон)** — разворачивает/сворачивает ветку (например, «React + TypeScript» → Hooks, State Management, Performance).
  - **Клик по названию навыка** — выбирает ветку и подгружает рекомендации справа.
  - **«Редактировать навыки»** — открывает редактор:
    - По каждому навыку — **ползунок 0–100%** (уровень владения).
    - **«Сохранить»** — обновляет дерево и пересчитывает AI‑подбор. **«Отмена»** — закрывает.
- **Панель «Рекомендации»** (справа) — после клика по ветке показывает:
  - **Вакансии**, требующие этот навык (кликабельны),
  - **Материалы** Career Hub по теме (кликабельны).

**Вкладка «Проекты»:**
- **«Добавить проект»** — окно создания:
  - Название, описание, **технологии** (вводите и жмёте Enter — добавляется «чип»; ✕ убирает), Demo‑ссылка, ссылка на репозиторий.
  - **«Добавить»** / **«Отмена»**.
- **Карточки проектов** — название, описание, технологии, ссылки **«Код»** и **«Demo»**, и **🗑 (корзина)** для удаления.

**Вкладка «О себе»:**
- Текст «О себе» (редактируется через «Редактировать» в шапке).

### 2.5. Мои отклики (статус‑трекер) — `/app/applications`
- **Вкладки‑фильтры:** Все / На рассмотрении / Приглашения / Офферы / Отказы.
- **Карточка отклика:** компания, вакансия, **процент совпадения**, бейдж статуса и **визуальный трекер**:
  `⏳ На рассмотрении → ✅ Приглашение → 🎯 Оффер` (пройденные этапы подсвечены; отказ показывается отдельным красным блоком).
- Клик по названию вакансии → её детальная страница.
- Если откликов нет — пустое состояние с кнопкой **«К поиску вакансий»**.

### 2.6. Career Hub — `/app/career`
Центр подготовки к собеседованиям.

- **Вкладки‑фильтры:** Все / Гайды / Чеклисты / Разборы кода.
- **Поле поиска** по материалам.
- **Карточки материалов** — тип (Гайд/Чеклист/Разбор кода), название, краткое описание, категория, время чтения, бейдж **«Пройдено»** (если завершено). Клик открывает материал.

#### Страница материала — `/app/career/:slug`
- **«К Career Hub»** — возврат.
- **Шапка** — категория, время чтения, заголовок, описание, теги.
- Содержимое зависит от типа:
  - **Гайд** — форматированный текст (заголовки, списки, выделения).
  - **Чеклист** — интерактивный список: **клик по пункту** отмечает его выполненным (✓ и зачёркивание).
  - **Разбор кода** (например, React useEffect или Python):
    - **Вкладки «❌ Плохое решение» / «✅ Хорошее решение»** — переключают примеры кода.
    - **«Копировать»** — копирует код в буфер обмена.
    - Блок **«Почему так лучше»** — объяснение.
    - Блок **«Что может спросить интервьюер»** — список вопросов.
    - **Тренажёр «Попробуйте сами»** — редактируемое поле с кодом; **«Сбросить»** возвращает эталонный вариант.
- **«Отметить пройденным»** — отмечает материал как изученный (влияет на прогресс на главной). После этого кнопка показывает «Пройдено».

## 3. Сценарий КОМПАНИИ (end-to-end)

Войдите как `company@techintern.ru` / `password123` (компания DevHorizon).

### 3.1. Дашборд компании — `/app`
- Название компании и **«Разместить вакансию»** (→ форма создания).
- **4 карточки‑метрики:** Активных вакансий, Всего откликов, Средний match, **Конверсия в оффер**.
- **«Воронка откликов»** — счётчики по статусам (⏳ ✅ 🎯 ❌).
- **«Ваши вакансии»** — список; клик по вакансии ведёт к её откликам.

### 3.2. Мои вакансии — `/app/company/vacancies`
- **«Разместить вакансию»** — создать новую.
- **Карточка вакансии:** название, бейдж статуса (Активна/Закрыта), уровень, формат, зарплата, число откликов, и кнопки:
  - **«Отклики»** — список откликнувшихся кандидатов.
  - **✏️ (карандаш)** — редактировать вакансию.
  - **🗑 (корзина)** — удалить (с подтверждением).

### 3.3. Создание / редактирование вакансии — `/app/company/vacancies/new` (или `/:id/edit`)
- **«К вакансиям»** — возврат.
- **Блок «Основное»:** название, описание, **Формат / Занятость / Уровень** (выпадающие списки), город, опыт (лет), зарплата «от» и «до».
- **Блок «Требуемые навыки»:**
  - **«Добавить навык»** — список навыков по категориям; отмеченные добавляются в набор.
  - У каждого навыка — переключатель **«Обязательный»** и **✕** для удаления. Чем точнее набор, тем точнее AI‑подбор кандидатов.
- **Блок «Детали»:** три списка — **Обязанности**, **Требования**, **Условия**. В каждом: введите пункт и нажмите Enter или **＋**; **✕** удаляет пункт.
- **«Опубликовать»** (или **«Сохранить»** при редактировании) / **«Отмена»**.

### 3.4. Отклики на вакансию — `/app/company/vacancies/:id/applicants`
- **«К вакансиям»** — возврат.
- Список кандидатов, **отсортированный по проценту совпадения** (лучшие сверху):
  - **Кольцо совпадения** — наглядный match‑score.
  - **Имя** (клик → профиль кандидата), заголовок, уровень, вуз, число проектов, сопроводительное письмо.
  - **Выпадающий список статуса** — смена этапа: ⏳ На рассмотрении → ✅ Приглашение → 🎯 Оффер → ❌ Отказ. При выборе «Приглашение»/«Оффер» автоматически открывается диалог с кандидатом.
  - **💬 (написать)** — открыть переписку с кандидатом.

### 3.5. Кандидаты — `/app/candidates`
Поиск талантов по всей базе.

- **«Ранжировать под вакансию»** — выпадающий список ваших вакансий. Если выбрать вакансию, кандидаты сортируются по AI‑совпадению с ней (на карточках появляется кольцо match‑score).
- **«Направление»** — фильтр по специализации (Frontend, Backend, Data Science…).
- **Поле поиска** — по имени или навыку.
- **Карточки кандидатов** — аватар, имя, заголовок, уровень, направление, город, вуз, топ‑навыки. Клик → профиль кандидата.
- **Пагинация** — **«Назад»** / **«Вперёд»**.

### 3.6. Профиль кандидата — `/app/candidates/:id`
- **«К кандидатам»** — возврат.
- Шапка: аватар, имя, заголовок, уровень/направление/город/вуз, ссылка **GitHub**.
- **«Написать»** — открывает переписку с кандидатом и переводит в «Сообщения».
- Блоки: «О себе», **Навыки** (с прогресс‑полосами), **Проекты** (со ссылками «Код»/«Demo»).

### 3.7. Профиль компании — `/app/company`
- Редактируемая форма: название, сфера, город, **размер компании** (список), сайт, описание.
- **«Сохранить»** — сохраняет изменения (эти данные видят кандидаты в вакансиях).

## 4. Общие разделы (студент и компания)

### 4.1. Сообщения — `/app/messages`
Чат «рекрутёр ↔ студент».
- **Левая колонка** — список диалогов (собеседник, последнее сообщение). Клик открывает переписку.
- **Правая колонка** — лента сообщений: ваши справа (фиолетовые), собеседника слева. Сообщения автоматически помечаются прочитанными.
- **Поле ввода «Напишите сообщение…»** и кнопка **➤ (отправить)** — отправляет сообщение.
- На телефоне: **← (назад)** возвращает к списку диалогов.
- Если диалогов нет — подсказка, как их начать (студенту — после приглашения; компании — из откликов или профиля кандидата).

### 4.2. Настройки — `/app/settings`
- **«Аккаунт»** — email и роль (информационно).
- **«Тема оформления»** — три кнопки: **Светлая / Тёмная / Системная** (текущая подсвечена).
- **«Выйти»** — завершает сессию и возвращает на главную.

## 5. Полезные сквозные сценарии

**Студент — от профиля до оффера:**
1. Заполните профиль и дерево навыков (Профиль → «Редактировать», «Редактировать навыки»).
2. Найдите вакансию (Поиск → фильтр по технологиям).
3. Откройте вакансию, посмотрите свой % совпадения, нажмите **«Откликнуться»**.
4. Следите за статусом в **«Мои отклики»**.
5. Параллельно готовьтесь в **Career Hub** (особенно разборы кода).

**Компания — от вакансии до найма:**

2. Откройте **«Отклики»** — кандидаты уже отсортированы по совпадению.
3. Меняйте статус (Приглашение/Оффер) — автоматически откроется чат.
4. Ищите дополнительно через **«Кандидаты»** с ранжированием под вакансию.
